Conclusion: TrashNet's own hosted dataset archive, every Kaggle waste-
classification dataset, and every host that serves pretrained MobileNetV2
ImageNet weights (Keras applications, TensorFlow Hub, PyTorch Hub, Hugging
Face) were unreachable from this sandbox. Only Python/Node package
registries and plain-text GitHub file content could be reached. This is why
app/classifier/inference.py builds MobileNetV2 with weights=None and why no
classification-accuracy result appears anywhere in Chapter Four.
