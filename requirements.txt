# numpy<2 is required here, not just preferred: tflite-runtime==2.14.0's prebuilt wheel is compiled

# Real production incident (2026-09-14, not hypothetical): serving predictions with full
# tensorflow-cpu==2.21.0 got the Render web worker SIGKILL'd for exceeding Render's 512MB free/Starter
# RAM limit -- confirmed via Render's own logs ("Worker ... was sent SIGKILL! Perhaps out of memory?")
# and reproduced here (loading one model + one prediction peaked at ~654MB RSS with full tensorflow).
# Fix: both trained models (app/classifier/artifacts/*.tflite) are now served via tflite-runtime
# instead, which peaked at ~48MB RSS for the same prediction in the same measurement, and was verified
# to produce bit-identical output to the original Keras models on every held-out fixture before this
# switch shipped. Full tensorflow-cpu is NOT a production dependency anymore -- see requirements-dev.txt
# if you need it for local training/conversion work or for running tests/test_model_architecture.py.
tflite-runtime==2.14.0
